プライバシーポリシー

更新日：2026年11月13日

Folioは、画像・アートワークを保存、整理、共有するサービスです。運営者はShota Nakagawaです。

取り扱う情報と利用目的

  • ログインに使用したアカウントの識別子、メールアドレス、表示名：本人確認、アカウントの管理、グループ共有に使用します。Appleの非公開メールアドレスも利用できます。
  • 作品画像、タイトル、タグ、コレクション、グループと共有メンバー：画像の保存、検索、プレビュー、コピー、選択したメンバーへの共有に使用します。
  • ログインセッションと外部サービスの認証情報：ログイン状態とGoogle Drive接続の維持に使用します。外部サービスの認証トークンは暗号化して保存します。AppleやGoogleのパスワードをFolioが取得することはありません。
  • サービスへのアクセスに伴う通信情報：障害の調査、不正アクセスの防止、サービスの運用に使用します。

画像の保存先と共有

Google Driveに接続している場合、アップロードした画像は自分のDriveに保存されます。未接続の場合は、Folioが管理する非公開のGoogle Cloud Storageに保存されます。Driveの閲覧用プレビューは必要に応じて取得し、キャッシュします。

Google Driveへの接続は任意です。接続だけで自分のDrive全体が他のユーザーに公開されることはありません。グループに登録した作品は、そのグループに参加しているメンバーにも表示されます。

利用する外部サービス

サービス運営のため、Google Cloud（APIの実行、画像と秘密情報の保存）、Turso（アカウント、作品情報、暗号化した認証情報の保存）、AppleまたはGoogle（ログイン）、任意でGoogle Driveを使用します。各社のサービスにも各社のプライバシーポリシーが適用されます。

サンプル作品の表示にはUnsplash配信の画像を使用します。この画像を読み込む際は配信元との通信が発生します。Folioは広告配信や、他社のアプリ・サイトをまたぐ広告目的の追跡には情報を利用しません。

Googleユーザーデータの利用

Google APIから取得した情報の利用・他サービスへの転送は、Google API Services User Data PolicyのLimited Use要件に従います。Drive情報は、ユーザーが選んだ画像の表示、取り込み、保存など、Folioの機能を提供するために使用し、広告やAIモデルの学習には使用しません。

保存期間と削除

アカウントの利用に必要な間、情報を保存します。アカウント削除を完了すると、Folioのアカウント、作品情報、共有設定、管理しているCloud Storage画像、ログインセッションと外部認証情報を削除します。外部サービスの認証も解除します。

Google Driveの元ファイルや、FolioからDriveへアップロードしたファイルは、ユーザー所有のDriveに残ります。削除したい場合はGoogle Driveで操作してください。削除の再試行や処理中の書き込み防止に必要な最小限の状態、および外部基盤の運用ログが、一時的に残る場合があります。
